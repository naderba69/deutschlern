# B1.12 — الابتكار والإبداع والبحث: التوقّعات بـFutur I

**المدة:** 40–45 دقيقة · **المهارات:** قراءة، استماع، قواعد، مفردات البحث، عرض فكرة وتحدث شفهي<br>
**الهدف:** أستطيع أن أتحدث عن توقع أو خطة مستقبلية باستخدام **Futur I**، وأن أوضح درجة التأكد بكلمات مثل **vielleicht** و**wahrscheinlich**.

## 1) مفردات البحث والابتكار

| الألمانية | الجمع/التصريف | المعنى |
|---|---|---|
| die Forschung | — | البحث العلمي |
| die Entwicklung | die Entwicklungen | التطوير / التطوّر |
| die Erfindung | die Erfindungen | الاختراع |
| das Experiment | die Experimente | التجربة |
| der Versuch | die Versuche | المحاولة / الاختبار |
| das Ergebnis | die Ergebnisse | النتيجة |
| die Anwendung | die Anwendungen | التطبيق |
| die Lösung | die Lösungen | الحل |
| der Prototyp | die Prototypen | النموذج الأولي |
| das Labor | die Labore | المختبر |
| entwickeln | entwickelt | يطوّر |
| erforschen | erforscht | يبحث في / يستكشف علميًا |
| testen | testet | يختبر |
| verbessern | verbessert | يحسّن |
| wahrscheinlich / vermutlich | — | على الأرجح |
| vielleicht / künftig | — | ربما / مستقبلًا |

## 2) التوقّع أو الخطة المستقبلية بـFutur I

يتكوّن **Futur I** من الفعل المساعد **werden** مصرّفًا، ثم المصدر في نهاية الجملة. نستخدمه للحديث عن توقّعات أو خطط مستقبلية، لكنه ليس لازمًا لكل جملة تشير إلى المستقبل؛ يمكن أيضًا استعمال **Präsens** مع وقت محدد لخطة متفق عليها، مثل: **Das Team testet den Prototyp nächste Woche.** وتوضح كلمات مثل **vielleicht, wahrscheinlich, vermutlich** أن التوقّع ليس حقيقة مؤكدة.

| الضمير | werden |
|---|---|
| ich | werde |
| du | wirst |
| er / sie / es | wird |
| wir | werden |
| ihr | werdet |
| sie / Sie | werden |

- **Das Team wird den Prototyp nächste Woche testen.** — سيختبر الفريق النموذج الأولي الأسبوع المقبل.
- **In Zukunft werden Forschende neue Lösungen entwickeln.** — سيطوّر الباحثون حلولًا جديدة في المستقبل.
- **Vielleicht wird das Experiment länger dauern.** — ربما تستغرق التجربة وقتًا أطول.

يأتي **werden** المصرف في الموقع الثاني، ويأتي المصدر في نهاية الجملة: **wird … testen**. انتبه إلى الفرق:

- **Das Team wird den Sensor testen.** — سيختبر الفريق المستشعر. (**Futur I:** المصدر **testen**)
- **Der Sensor wird getestet.** — يُختبر المستشعر. (**Präsens Passiv:** Partizip II **getestet**)

## 3) حوار أصلي في ورشة ابتكار

**Rana:** Woran arbeitet euer Team gerade?  
**Timo:** Wir entwickeln einen kleinen Sensor für den Gemeinschaftsgarten.  
**Rana:** Was werdet ihr als Nächstes machen?  
**Timo:** Nächste Woche werden wir den Prototyp in zwei Beeten testen.  
**Rana:** Wird der Sensor die Arbeit im Garten ersetzen?  
**Timo:** Nein. Er wird nur Messwerte liefern. Wir werden prüfen, ob die Werte hilfreich sind.  
**Rana:** Und was passiert, wenn der erste Versuch nicht klappt?  
**Timo:** Dann werden wir das Modell verbessern. Ein Versuch, der nicht funktioniert, wird uns trotzdem etwas zeigen.

## 4) نص قراءة أصلي: مشروع بحثي خيالي

> Eine Schülergruppe im fiktiven „Zukunftslabor“ entwickelt einen Sensor für einen Gemeinschaftsgarten. Zuerst baut sie einen Prototyp, der die Feuchtigkeit in der Erde misst. Im nächsten Monat wird das Team den Sensor in zwei Beeten testen und die Messwerte notieren. Die Gruppe erwartet, dass der Prototyp beim Planen der Gartenarbeit helfen wird; er wird die Erfahrung der Gärtnerinnen und Gärtner aber nicht ersetzen. Nach dem ersten Versuch werden die Schülerinnen und Schüler die Ergebnisse vergleichen. Wenn ein Teil nicht zuverlässig funktioniert, werden sie das Modell verändern. Vielleicht entsteht daraus eine neue Idee. Das Ziel des Projekts ist nicht, sofort ein perfektes Gerät zu bauen, sondern eine Frage Schritt für Schritt zu untersuchen.

### أسئلة الفهم

1. Wer entwickelt den Sensor?
2. Was misst der Prototyp?
3. Was wird das Team im nächsten Monat tun?
4. Was wird der Sensor laut Text nicht ersetzen?
5. Was macht die Gruppe, wenn ein Teil nicht zuverlässig funktioniert?
6. Was ist das Ziel des Projekts?

## 5) نص استماع معدّ للنطق

> In unserem Innovationskurs untersuchen wir, wie auf dem Schulhof mehr Schatten entstehen kann. In zwei Wochen werden wir Modelle aus Karton vorstellen. Danach werden wir Rückmeldungen sammeln. Wahrscheinlich werden wir zwei Entwürfe verbessern. Vielleicht wird die Gruppe am Ende nicht das schönste, sondern das praktischste Modell auswählen. Wir wissen noch nicht, welche Idee am besten funktioniert.

أجب:

1. Was untersucht die Gruppe?
2. Was wird sie in zwei Wochen vorstellen?
3. Was wird sie danach sammeln?
4. Was wird sie wahrscheinlich verbessern?
5. Welches Modell wird die Gruppe vielleicht auswählen?

## 6) التمارين

### تمرين 1 — اختر المفردة المناسبة

1. نموذج أولي لمنتج أو فكرة: **der Prototyp / das Ergebnis**
2. مكان تُجرى فيه التجارب: **das Labor / die Anwendung**
3. ما ينتج عن تجربة أو اختبار: **das Ergebnis / die Entwicklung**
4. فحص فكرة أو جهاز للتأكد من عمله: **testen / erfinden**

### تمرين 2 — أكمل صيغة werden

1. Ich ______ die Ergebnisse morgen vergleichen.
2. Du ______ den Prototyp nächste Woche testen.
3. Das Team ______ vielleicht eine neue Lösung entwickeln.
4. Wir ______ die Anwendung später verbessern.
5. ______ Sie das Experiment wiederholen?

### تمرين 3 — ضع المصدر في نهاية الجملة

1. Die Gruppe wird den Sensor morgen ______. (testen)
2. Wir werden die Ergebnisse später ______. (vergleichen)
3. Die Forscherin wird eine neue Lösung ______. (entwickeln)

### تمرين 4 — أضف كلمة التوقّع في المكان المناسب

استخدم **wahrscheinlich** أو **vielleicht** أو **vermutlich**:

1. ______ wird das Experiment länger dauern.
2. Das Team wird ______ einen zweiten Prototyp bauen.
3. ______ werden die Ergebnisse neue Fragen aufwerfen.

### تمرين 5 — فهم القراءة

حدّد صحيحًا أو خطأ:

1. المشروع البحثي مذكور بوصفه مشروعًا حقيقيًا في مختبر معروف.
2. يقيس النموذج الأولي رطوبة التربة.
3. سيختبر الفريق المستشعر في حوضين للزراعة.
4. سيحل المستشعر محل خبرة البستانيين.
5. سيغيّر الطلاب النموذج إذا لم يعمل جزء منه بموثوقية.

### تمرين 6 — فهم الاستماع

أكمل بالألمانية: 1. Die Gruppe untersucht, wie auf dem Schulhof mehr ______ entstehen kann. 2. In zwei Wochen werden sie Modelle aus ______ vorstellen. 3. Danach werden sie ______ sammeln. 4. Wahrscheinlich wird die Gruppe zwei ______ verbessern. 5. Vielleicht wird die Gruppe am Ende das ______ Modell auswählen.

### تمرين 7 — ميّز بين Futur I والمبني للمجهول في المضارع

اكتب **Futur I** أو **Präsens Passiv**:

1. **Das Team wird den Sensor testen.**
2. **Der Sensor wird getestet.**
3. **Forscherinnen werden eine Lösung entwickeln.**
4. **Die Ergebnisse werden veröffentlicht.**

### تمرين 8 — توقّع ابتكارًا

اكتب عرضًا من خمس جمل ألمانية على الأقل عن مشروع ابتكار خيالي، أو قدّمه شفهيًا. اذكر خطة واحدة وتوقعين بدرجتي يقين مختلفتين، مثل **vielleicht** و**wahrscheinlich**، واستخدم **Futur I** مرتين على الأقل. لخطة ذات موعد متفق عليه يمكنك استعمال **Präsens** مع تعبير زمني. اجعل التوقعات احتمالات لا حقائق مؤكدة. إن كنت تتعلم وحدك فاكتب النص ثم اقرأه بصوت واضح؛ لا يلزم تسجيل، ولا تنسب التوقع إلى بحث حقيقي.

## 7) مفتاح الإجابات

**أسئلة القراءة:** 1. Eine Schülergruppe im fiktiven Zukunftslabor. 2. Die Feuchtigkeit in der Erde. 3. Sie wird den Sensor in zwei Beeten testen und die Messwerte notieren. 4. Die Erfahrung der Gärtnerinnen und Gärtner. 5. Sie werden das Modell verändern. 6. Eine Frage Schritt für Schritt zu untersuchen.

**أسئلة الاستماع:** 1. Wie auf dem Schulhof mehr Schatten entstehen kann. 2. Modelle aus Karton. 3. Rückmeldungen. 4. Zwei Entwürfe. 5. Vielleicht wird die Gruppe das praktischste Modell auswählen.

- **تمرين 1:** 1. der Prototyp، 2. das Labor، 3. das Ergebnis، 4. testen.
- **تمرين 2:** 1. werde، 2. wirst، 3. wird، 4. werden، 5. Werden.
- **تمرين 3:** 1. testen، 2. vergleichen، 3. entwickeln.
- **تمرين 4:** 1. Vielleicht، 2. wahrscheinlich، 3. Vermutlich. *(يمكن تبديل كلمات التوقّع إذا بقي المعنى طبيعيًا.)*
- **تمرين 5:** 1. خطأ — المشروع خيالي. 2. صحيح. 3. صحيح. 4. خطأ — لا يحل محل خبرة البستانيين. 5. صحيح.
- **تمرين 6:** Schatten؛ Karton؛ Rückmeldungen؛ Entwürfe؛ praktischste.
- **تمرين 7:** 1. Futur I، 2. Präsens Passiv، 3. Futur I، 4. Präsens Passiv.
- **تمرين 8:** إجابة مفتوحة؛ تحقّق من ذكر خطة وتوقعين بدرجتي يقين، وصحة **werden** وموضع المصدر. يمكن تقديمه شفهيًا؛ وللتعلم الفردي يُكتب النص ويُقرأ بصوت واضح دون تسجيل. لا يلزم استخدام **Futur I** في كل جملة مستقبلية.

## 8) بطاقات مراجعة

- **Das Team wird den Prototyp testen.** → سيختبر الفريق النموذج الأولي.
- **Vielleicht wird das Experiment länger dauern.** → ربما تستغرق التجربة وقتًا أطول.
- **der Versuch / das Ergebnis** → المحاولة أو الاختبار / النتيجة.
- **Der Sensor wird getestet.** → يُختبر المستشعر.
