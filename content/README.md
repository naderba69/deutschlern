# المحتوى الدراسي

تُكتب الدروس وتُراجع في ملفات Markdown داخل `content/`. هذه الملفات هي المصدر التحريري الأساسي، ويُحوّلها `tools/build_course.py` إلى بيانات يقرأها التطبيق في `data/course.json`.

## بنية المسار

- **A0:** خمس وحدات تأسيسية أصلية، واختبار انتقال إضافي قصير إلى A1.
- **A1 وA2 وB1 وB2:** اثنتا عشرة وحدة لكل مستوى، وفق خريطة Spektrum في `../data/source-plan.md`.
- **الإجمالي:** 53 وحدة دراسية، إضافة إلى اختبار A0 الانتقالي.

## ما يتضمنه الدرس

تشمل الدروس أهداف التواصل، شروحًا عربية، مفردات وأمثلة ألمانية، نقاط القواعد، حوارات أو نصوصًا قصيرة، نصوص قراءة واستماع معدّة للتعلّم، تمارين متنوعة، ومفاتيح إجابات. تُعرض المادة كاملة داخل التطبيق؛ ومفاتيح الإجابات مخفية في عنصر قابل للفتح إلى أن يحاول المتعلم حل التمرين.

التمارين والحوارات هنا **أصلية** وليست نسخًا من تمارين Spektrum. السلسلة مرجع للتدرج والموضوعات، ولا تدخل ملفات PDF أو صفحاتها في هذا المشروع.

## لغة المحتوى

الشرح والتعليمات بالعربية الفصحى المبسطة، والأمثلة والمواد التي يتعلمها الطالب بالألمانية. تُقبل إجابات متعددة في الأنشطة المفتوحة، ويُذكر نموذج إجابة أو معيار تقييم بدل افتراض حل وحيد.

## التقدم والتحقق

حالة الوحدات الـ53 ونتائج الفحص النهائي موثقة في `PROGRESS.md`. لإعادة بناء حزمة المنهج وتشغيل اختبارات التكامل من جذر المشروع:

```bash
python3 tools/build_course.py
python3 tools/verify_course.py
```

التمارين تظهر كاملة، لكنها ليست مصحّحة آليًا بعد؛ يقارن المتعلم إجاباته بمفتاح الإجابات.
