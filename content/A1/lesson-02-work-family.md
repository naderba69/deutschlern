# A1.2 — الأسرة والمهن

**المدة:** 30 دقيقة · **المهارات:** مفردات، قراءة، استماع قصير، محادثة وكتابة  
**هدف التواصل:** أستطيع أن أصف أسرتي وأذكر مهنة شخص وأسأل عن عمله.

## 1) مفردات الأسرة

| الألمانية | الجمع | المعنى |
|---|---|---|
| die Familie | die Familien | الأسرة |
| der Vater | die Väter | الأب |
| die Mutter | die Mütter | الأم |
| der Bruder | die Brüder | الأخ |
| die Schwester | die Schwestern | الأخت |
| der Sohn | die Söhne | الابن |
| die Tochter | die Töchter | الابنة |
| das Kind | die Kinder | الطفل/الابن أو الابنة |
| die Eltern | — (جمع) | الوالدان |
| der Großvater | die Großväter | الجد |
| die Großmutter | die Großmütter | الجدة |

## 2) المهن والأفعال

| الألمانية | المعنى | مثال |
|---|---|---|
| der Lehrer / die Lehrerin | معلّم / معلّمة | Mein Onkel ist Lehrer. |
| der Arzt / die Ärztin | طبيب / طبيبة | Meine Tante ist Ärztin. |
| der Koch / die Köchin | طاهٍ / طاهية | Er arbeitet als Koch. |
| der Verkäufer / die Verkäuferin | بائع / بائعة | Sie arbeitet als Verkäuferin. |
| der Student / die Studentin | طالب جامعي / طالبة جامعية | Mein Bruder ist Student. |
| arbeiten | يعمل | Ich arbeite in einem Café. |
| studieren | يدرس في الجامعة | Sie studiert Medizin. |
| heißen | يُدعى | Mein Bruder heißt Sami. |

بعد **sein** نذكر المهنة غالبًا بلا أداة تعريف: **Ich bin Lehrerin.** وللحديث عن العمل نستطيع قول: **Ich arbeite als Lehrerin.**

## 3) القواعد: mein وdein

تتغير نهاية **mein** و**dein** بحسب الاسم الذي يأتي بعدهما:

| الاسم | «أخي/أختي» |
|---|---|
| der Vater / der Bruder | mein Vater / mein Bruder |
| die Mutter / die Schwester | meine Mutter / meine Schwester |
| das Kind | mein Kind |
| die Eltern (جمع) | meine Eltern |

الأمر نفسه مع **dein/deine**:

- **dein Bruder** — أخوك.
- **deine Schwester** — أختك.

للتعريف بشخص: **Das ist mein Bruder. Er heißt Nabil.** / **Das ist meine Schwester. Sie heißt Amel.**

### تذكير بتصريف arbeiten

| ich | arbeite |
| du | arbeitest |
| er/sie | arbeitet |
| wir | arbeiten |
| ihr | arbeitet |
| sie/Sie | arbeiten |

## 4) أسئلة عن العمل والأسرة

- **Was bist du von Beruf?** — ما مهنتك؟
- **Was machen Sie beruflich?** — ماذا تعمل/تعملين؟ (رسمي)
- **Wo arbeitet dein Vater?** — أين يعمل والدك؟
- **Hast du Geschwister?** — هل لديك إخوة أو أخوات؟
- **Ja, ich habe einen Bruder. / Nein, ich habe keine Geschwister.**

## 5) نص قراءة أصلي

> Ich heiße Rania und wohne in Nabeul. Meine Familie ist nicht sehr groß. Mein Vater ist Koch und arbeitet in einem Hotel. Meine Mutter ist Lehrerin. Ich habe einen Bruder und eine Schwester. Mein Bruder Sami studiert in Tunis. Meine Schwester Amel ist noch Schülerin. Am Sonntag besuchen wir oft unsere Großmutter.

### أسئلة الفهم

1. Wo wohnt Rania?
2. Was ist ihr Vater von Beruf?
3. Wo studiert Sami?
4. Hat Rania eine Schwester?
5. Wen besucht die Familie oft am Sonntag?

## 6) نص الاستماع المعدّ للتسجيل أو النطق

> Guten Tag! Ich bin Youssef. Mein Vater arbeitet in einer Werkstatt. Er ist Mechaniker. Meine Mutter ist Ärztin und arbeitet in einer Klinik. Meine Schwester heißt Leila. Sie studiert an der Universität.

أجب بعد الاستماع أو القراءة:

1. Was ist Youssefs Vater von Beruf?
2. Wo arbeitet seine Mutter?
3. Was macht Leila?

## 7) التمارين

### تمرين 1 — اختر المفردة

1. أخت: **der Bruder / die Schwester**
2. الوالدان: **die Eltern / die Kinder**
3. طبيبة: **die Ärztin / der Arzt**
4. الابنة: **die Tochter / der Sohn**

### تمرين 2 — أكمل بـmein أو meine

1. ______ Vater ist Lehrer.
2. ______ Schwester heißt Sara.
3. ______ Eltern wohnen in Tunis.
4. ______ Kind ist fünf Jahre alt.

### تمرين 3 — أكمل الفعل

1. Ich ______ in einer Schule. (arbeiten)
2. Du ______ in einem Café. (arbeiten)
3. Meine Mutter ______ als Ärztin. (arbeiten)
4. Wir ______ an der Universität. (studieren)

### تمرين 4 — كوّن جملة

1. meine / ist / Schwester / Ärztin
2. Vater / als Koch / arbeitet / mein
3. heißt / Bruder / Mein / Sami

### تمرين 5 — اسأل عن المهنة

اكتب السؤال المناسب لكل جواب:

1. ______? — Ich bin Lehrerin.
2. ______? — Mein Vater arbeitet in einem Hotel.
3. ______? — Nein, ich habe keine Geschwister.

### تمرين 6 — فهم القراءة

حدّد **صحيح أو خطأ**، ثم صحّح الخطأ:

1. Rania wohnt in Tunis.
2. Ihr Vater ist Koch.
3. Sami arbeitet in Nabeul.
4. Die Familie besucht oft die Großmutter.

### تمرين 7 — فهم الاستماع

اختر الجواب الصحيح:

1. Youssefs Vater ist … أ. Mechaniker ب. Student
2. Seine Mutter arbeitet … أ. in einer Schule ب. in einer Klinik
3. Leila … أ. studiert ب. arbeitet als Ärztin

### تمرين 8 — ملف عائلي قصير

اكتب 5 جمل عن أسرة حقيقية أو متخيلة. استخدم **mein/meine** ومهنة واحدة على الأقل. لا يلزم مشاركة معلومات شخصية حقيقية.

### تمرين 9 — محادثة ثنائية

اسأل زميلك: **Hast du Geschwister? Was machen deine Eltern beruflich?** ثم لخّص إجابته بجملتين. للتمرين الفردي اكتب سؤالًا وجوابًا لكل نقطة.

## 8) مفتاح الإجابات

- **تمرين 1:** 1. die Schwester، 2. die Eltern، 3. die Ärztin، 4. die Tochter.
- **تمرين 2:** 1. Mein، 2. Meine، 3. Meine، 4. Mein.
- **تمرين 3:** 1. arbeite، 2. arbeitest، 3. arbeitet، 4. studieren.
- **تمرين 4:** 1. Meine Schwester ist Ärztin. 2. Mein Vater arbeitet als Koch. 3. Mein Bruder heißt Sami.
- **تمرين 5:** 1. Was bist du von Beruf? 2. Wo arbeitet dein Vater? 3. Hast du Geschwister?
- **تمرين 6:** 1. خطأ — Rania wohnt in Nabeul. 2. صحيح. 3. خطأ — Sami studiert in Tunis. 4. صحيح.
- **تمرين 7:** 1. أ، 2. ب، 3. أ.
- **تمرين 8 و9:** إجابات مفتوحة؛ راجع mein مع المذكر والمحايد، وmeine مع المؤنث والجمع.

## 9) بطاقات مراجعة

- **mein Bruder / meine Schwester** → أخي / أختي.
- **Was bist du von Beruf?** → ما مهنتك؟
- **Ich arbeite als …** → أعمل بوظيفة …
- **Hast du Geschwister?** → هل لديك إخوة أو أخوات؟
