# A0.5 — عبارات الصف وطلب المساعدة

**المدة:** 20 دقيقة · **المهارات:** قراءة، كتابة، تفاعل ومحادثة مباشرة · **الهدف:** أستطيع طلب التكرار أو التوضيح، وأقول إنني لا أفهم كلمة. التسجيلات الموجودة متاحة للاستماع؛ لا نحتاج إلى تسجيل صوتك أو مشاركة بيانات شخصية لإنجاز الأنشطة.

## 1) عبارات مفيدة

| الألمانية | المعنى |
|---|---|
| Ich verstehe. | أفهم. |
| Ich verstehe nicht. | لا أفهم. |
| Bitte wiederholen Sie das. | من فضلك أعد ذلك. (رسمي) |
| Kannst du das bitte wiederholen? | هل يمكنك إعادة ذلك من فضلك؟ (غير رسمي) |
| Langsamer, bitte. | أبطأ، من فضلك. |
| Was bedeutet …? | ماذا تعني …؟ |
| Wie schreibt man …? | كيف تُكتب …؟ |
| Können Sie mir helfen? | هل يمكن أن تساعدني؟ (رسمي) |
| Ich habe eine Frage. | لدي سؤال. |
| Danke für Ihre Hilfe. | شكرًا لحضرتك/حضراتكم على المساعدة. (رسمي) |

## 2) ملاحظة مهذبة

- **du**: للمخاطبة غير الرسمية، مثل صديق أو شخص اتفقت معه على ذلك؛ يمكن أن يكون الطلب بهذه الصيغة مهذبًا أيضًا.
- **Sie**: للمخاطبة الرسمية. في أنشطة هذا الدرس نستعملها مع المدرّسة، ولا نفترض أن كل صف يستعمل Sie دائمًا.
- **bitte** تساعد على تلطيف الطلب مع نبرة مناسبة، و**Danke** للشكر. نكتب **Sie/Ihre** الرسمية بحرف كبير، و**Frage** كبيرة لأنها اسم. **bitte** صغيرة داخل الجملة، وتصبح **Bitte** في بداية الجملة.

**ترتيب الطلب:** كل من **Bitte wiederholen Sie das.** و**Wiederholen Sie das bitte.** صحيح. عندما يطلب التمرين البدء بالفعل، نستعمل النمط الثاني؛ ليس معنى ذلك أن كل صيغة أخرى خاطئة.

**المعنى والكتابة:** **Was bedeutet …?** تسأل عن المعنى، و**Wie schreibt man …?** تسأل عن طريقة الكتابة؛ لا يلزم أن تكون الإجابة تهجئة شفوية حرفًا حرفًا.

**مفردات مساعدة لفهم المواقف، لا درس قواعد جديد:**

- das Wort = الكلمة؛ der Satz = الجملة؛ der Unterricht = الدرس/الحصة.
- pünktlich = في الموعد المحدد؛ der Termin = الموعد (المتفق عليه في مثالنا)؛ Entschuldigung = عذرًا.
- Welches Wort? = أي كلمة؟؛ Kein Problem. = لا مشكلة؛ Ja, natürlich. = نعم، بالطبع.

## 3) حوار أصلي

**Lernender:** Entschuldigung, ich verstehe das Wort nicht. Was bedeutet „pünktlich“?

**Lehrerin:** „Pünktlich“ bedeutet: zur richtigen Zeit.

**Lernender:** Danke. Können Sie das bitte wiederholen?

**Lehrerin:** Ja, natürlich.

**Lernender:** Danke für Ihre Hilfe.

**لفهم الحوار والتدرّب عليه:** المقصود بـ**pünktlich** هنا الالتزام بالوقت المحدد أو المتفق عليه، لا مجرد الحضور في أي وقت مناسب. جواب **Ja, natürlich.** موافقة على الإعادة، لكن النص المسجّل لا يعرض إعادة الشرح نفسها؛ بعده اقرأ جملة المعلمة التي تشرح الكلمة مرة أخرى. هذا تدريب نصي إضافي، وليس مقطعًا صوتيًا جديدًا.

## 4) تمارين

### تمرين 1 — صِل العبارة بمعناها

1. Ich verstehe nicht.  
2. Langsamer, bitte.  
3. Was bedeutet das?  
4. Ich habe eine Frage.  

أ. لدي سؤال. · ب. لا أفهم. · ج. أبطأ من فضلك. · د. ماذا يعني ذلك؟

### تمرين 2 — أكمل بالكلمة المناسبة

اختر من: **nicht — bitte — bedeutet — Frage**

1. Ich verstehe ______.
2. Langsamer, ______.
3. Was ______ „Buch“?
4. Ich habe eine ______.

### تمرين 3 — رسمي أم غير رسمي؟

1. Kannst du das wiederholen?
2. Können Sie mir helfen?
3. Bitte wiederholen Sie das.
4. Wie schreibt man das?

حدد أي العبارات تخاطب شخصًا بصيغة du وأيها تستخدم Sie. (الجملة الرابعة لا تحدد المخاطب وحدها.)

### تمرين 4 — رتّب الكلمات

ابدأ بالكلمة المحددة، ثم ضع علامة الترقيم في نهاية الجملة. المفتاح يقدم نموذجًا ممكنًا؛ قد توجد ترتيبات أخرى صحيحة ضمن المطلوب.

1. bitte / Sie / Wiederholen / das — ابدأ بـ**Wiederholen**؛ طلب رسمي.
2. bedeutet / Was / das — ابدأ بـ**Was**؛ سؤال عن المعنى.
3. Frage / eine / habe / Ich — ابدأ بـ**Ich**؛ جملة خبرية.
4. helfen / Sie / mir / Können — ابدأ بـ**Können**؛ سؤال طلب مساعدة.

### تمرين 5 — اختر الطلب اللطيف

في موقف تدريبي مع مدرّس تخاطبه بصيغة Sie، اختر طلبًا كاملًا ومهذبًا لإعادة الجملة:
أ. Wiederholen!  ب. Können Sie das bitte wiederholen?  ج. Ich bin eine Wiederholung.

### تمرين 6 — أكمل الحوار

**A:** Entschuldigung, ich verstehe ______.

**B:** Kein Problem. Welches Wort?

**A:** Was ______ „Termin“?

**B:** Ein Termin ist eine vereinbarte Zeit.

**A:** Danke ______ Ihre Hilfe.

### تمرين 7 — مهمة تواصل

الجملة المسموعة في الموقف المتخيّل: **Der Unterricht beginnt um neun Uhr.** — تبدأ الحصة في الساعة التاسعة. هي سياق جاهز؛ لا يُطلب شرح قواعد الوقت الآن.

اكتب مسودة طلباتك للمدرّسة بصيغة Sie، تشمل الأجزاء الخمسة، ثم قلها بصوت مرتفع بنفسك أو مع شريك إن توفر:

1. قل إنك لا تفهم الكلمة: **Ich verstehe das Wort nicht.**
2. اطلب إعادة الجملة بصيغة مهذبة.
3. اطلب الكلام ببطء.
4. اسأل عن معنى **Unterricht** باستخدام **Was bedeutet …?**
5. اسأل كيف تُكتب الكلمة باستخدام **Wie schreibt man …?**

لا يلزم شريك أو تسجيل صوتك؛ تدرب على قول الطلبات، ولا يلزم أن تؤلف أجوبة المدرّسة.

### تمرين 8 — بطاقة مساعدة شخصية

اختر ثلاث عبارات مختلفة من الدرس واكتب بجانب كل منها معناها بالعربية. ثم غطِّ الصياغة الألمانية، وانظر إلى المعنى العربي وحاول كتابة العبارة بالألمانية من الذاكرة. اكشف النموذج وقارن وصحح مسودتك. هذه مهمة كتابة؛ لا يلزم قولها بصوت مرتفع.

## 5) مفتاح الإجابات

- **تمرين 1:** 1-ب، 2-ج، 3-د، 4-أ.
- **تمرين 2:** 1. nicht، 2. bitte، 3. bedeutet، 4. Frage.
- **تمرين 3:** 1. du، 2. Sie، 3. Sie، 4. لا تحدد المخاطب وحدها.
- **تمرين 4 — نماذج ممكنة:** 1. Wiederholen Sie das bitte. 2. Was bedeutet das? 3. Ich habe eine Frage. 4. Können Sie mir helfen?
- **تمرين 5:** ب. Wiederholen! توجيه مختصر ممكن في سياقات أخرى، لكنه ليس الطلب الكامل المهذب المقصود هنا. Ich bin eine Wiederholung. تعني حرفيًا «أنا تكرار»، وليست طلب إعادة.
- **تمرين 6:** nicht؛ bedeutet؛ für. يسأل B أولًا «أي كلمة؟»، ثم يحدد A الكلمة ويسأل عن معناها؛ الجواب يشرح Termin في هذا السياق بأنه موعد بوقت متفق عليه. لا تسجيل مستقل لهذا الحوار.
- **تمرين 7 — نموذج ممكن:** Ich verstehe das Wort nicht. / Können Sie den Satz bitte wiederholen? / Langsamer, bitte. / Was bedeutet „Unterricht“? / Wie schreibt man „Unterricht“? المهم الأجزاء الخمسة، لا حفظ ترتيب وحيد لكل الصيغ الممكنة.
- **تمرين 8 — مثال لثلاث بطاقات:** Ich verstehe nicht. — لا أفهم. / Langsamer, bitte. — أبطأ، من فضلك. / Ich habe eine Frage. — لدي سؤال. يجوز اختيار غيرها من عبارات الدرس؛ احتفظ بثلاث عبارات مختلفة ومعانٍ مطابقة. راعِ Sie/Ihre والأسماء الكبيرة، وbitte الصغيرة داخل الجملة أو Bitte في بدايتها.

**حدود التقييم:** المهمات تحفظ مسودة وتأكيدات مراجعة ذاتية. طول النص أو اختيار مربعات التحقق لا يثبت صحة الألمانية أو النطق آليًا؛ قارن بالنماذج وصحح ما لاحظته.

## 6) بطاقات مراجعة

- **Ich verstehe nicht.** → لا أفهم.
- **Bitte wiederholen Sie das.** → أعد ذلك من فضلك.
- **Was bedeutet …?** → ماذا تعني …؟
- **Wie schreibt man …?** → كيف تُكتب …؟
- **Können Sie mir helfen?** → هل يمكن أن تساعدني؟
