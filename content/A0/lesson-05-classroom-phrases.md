# A0.5 — عبارات الصف وطلب المساعدة

**المدة:** 20 دقيقة · **المهارات:** استماع، تفاعل، قراءة · **الهدف:** أستطيع طلب التكرار أو التوضيح، وأقول إنني لا أفهم كلمة.

## 1) عبارات مفيدة

| الألمانية | المعنى |
|---|---|
| Ich verstehe. | أفهم. |
| Ich verstehe nicht. | لا أفهم. |
| Bitte wiederholen Sie das. | من فضلك أعد ذلك. (رسمي) |
| Kannst du das bitte wiederholen? | هل يمكنك إعادة ذلك من فضلك؟ (غير رسمي) |
| Langsamer, bitte. | أبطأ، من فضلك. |
| Was bedeutet …? | ماذا تعني …؟ |
| Wie schreibt man …? | كيف تُكتب …؟ |
| Können Sie mir helfen? | هل يمكن أن تساعدني؟ (رسمي) |
| Ich habe eine Frage. | لدي سؤال. |
| Danke für Ihre Hilfe. | شكرًا على مساعدتكم. |

## 2) ملاحظة مهذبة

- **du**: مع الأصدقاء أو شخص قريب.
- **Sie**: مع المدرّس أو شخص لا تعرفه أو في موقف رسمي.
- **bitte** يجعل الطلب ألطف، و**Danke** مناسبة بعد المساعدة.

## 3) حوار أصلي

**Lernende:** Entschuldigung, ich verstehe das Wort nicht. Was bedeutet „pünktlich“?  
**Lehrerin:** „Pünktlich“ bedeutet: zur richtigen Zeit.  
**Lernende:** Danke. Können Sie das bitte wiederholen?  
**Lehrerin:** Ja, natürlich.  
**Lernende:** Danke für Ihre Hilfe.

## 4) تمارين

### تمرين 1 — صِل العبارة بمعناها

1. Ich verstehe nicht.  
2. Langsamer, bitte.  
3. Was bedeutet das?  
4. Ich habe eine Frage.  

أ. لدي سؤال. · ب. لا أفهم. · ج. أبطأ من فضلك. · د. ماذا يعني ذلك؟

### تمرين 2 — أكمل بالكلمة المناسبة

اختر من: **nicht — bitte — bedeutet — Frage**

1. Ich verstehe ______.
2. Langsamer, ______.
3. Was ______ „Buch“?
4. Ich habe eine ______.

### تمرين 3 — رسمي أم غير رسمي؟

1. Kannst du das wiederholen?
2. Können Sie mir helfen?
3. Bitte wiederholen Sie das.
4. Wie schreibt man das?

حدد أي العبارات تخاطب شخصًا بصيغة du وأيها تستخدم Sie. (الجملة الرابعة لا تحدد المخاطب وحدها.)

### تمرين 4 — رتّب الكلمات

1. bitte / Sie / Wiederholen / das.
2. bedeutet / Was / das?
3. Frage / eine / habe / Ich.
4. helfen / Sie / mir / Können?

### تمرين 5 — اختر الطلب اللطيف

تريد طلب إعادة الجملة من المدرّس:
أ. Wiederholen!  ب. Können Sie das bitte wiederholen?  ج. Ich bin eine Wiederholung.

### تمرين 6 — أكمل الحوار

**A:** Entschuldigung, ich verstehe ______.  
**B:** Kein Problem. Was bedeutet das Wort?  
**A:** Ja, was ______ „Termin“?  
**B:** Ein Termin ist eine vereinbarte Zeit.  
**A:** Danke ______ Ihre Hilfe.

### تمرين 7 — مهمة تواصل

اقرأ الجملة التالية وكأنك في الصف: **Der Unterricht beginnt um neun Uhr.** اسأل المدرّس أن يعيدها ببطء، ثم اسأله كيف تُكتب كلمة **Unterricht**.

### تمرين 8 — بطاقة مساعدة شخصية

اكتب ثلاث عبارات تريد استعمالها في الصف. اختر من الدرس، ثم غطِّ الترجمة وحاول تذكرها بالألمانية.

## 5) مفتاح الإجابات

- **تمرين 1:** 1-ب، 2-ج، 3-د، 4-أ.
- **تمرين 2:** 1. nicht، 2. bitte، 3. bedeutet، 4. Frage.
- **تمرين 3:** 1. du، 2. Sie، 3. Sie، 4. لا تحدد المخاطب وحدها.
- **تمرين 4:** 1. Wiederholen Sie das bitte. 2. Was bedeutet das? 3. Ich habe eine Frage. 4. Können Sie mir helfen?
- **تمرين 5:** ب.
- **تمرين 6:** nicht؛ bedeutet؛ für.
- **تمرين 7:** نموذج: „Können Sie den Satz bitte wiederholen? Langsamer, bitte. Wie schreibt man ‚Unterricht‘?“
- **تمرين 8:** إجابة شخصية؛ راعِ كتابة bitte وSie وFrage بحروفها الصحيحة.

## 6) بطاقات مراجعة

- **Ich verstehe nicht.** → لا أفهم.
- **Bitte wiederholen Sie das.** → أعد ذلك من فضلك.
- **Was bedeutet …?** → ماذا تعني …؟
- **Wie schreibt man …?** → كيف تُكتب …؟
- **Können Sie mir helfen?** → هل يمكن أن تساعدني؟
