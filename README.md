## اختبار المتصفح والعمل دون اتصال

حزم npm للاختبار فقط؛ يبقى التطبيق موقعًا ثابتًا. بعد `npm ci` و`npx playwright install --with-deps chromium` شغّل `npm run test:browser`. يشغّل الاختبار خادمًا مؤقتًا ومتصفحًا معزولًا؛ ويمكن تعيين `CHROMIUM_EXECUTABLE_PATH` لمتصفح محلي. اختبار عامل الخدمة المستقل: `npm run test:service-worker`. اختبار لوحة المفاتيح وترقية المخزن: `npm run test:accessibility-update`. أُضيف `npm run test:forms-keyboard` للنماذج و`npm run test:accessibility-audit` للتدقيق الآلي. اختبار العرض الضيق والقصير: `npm run test:narrow-layout`. شغّل اختبارات المتصفح بالتتابع؛ لحفظ التفاصيل والمحددات البشرية استخدم `A11Y_REPORT=/tmp/accessibility.json npm run test:accessibility-audit`. axe-core وPlaywright تبعيتا تطوير فقط ولا يُحمّلان في تطبيق المستخدم.

**حدود التخزين:** تُحفظ ملفات الواجهة والحزمة، ثم التسجيلات المطلوبة عند جلبها كاملة؛ لا تُنزّل مكتبة الصوت كلها. تشغيل دور واحد لا يحفظ بقية الحوار. التحديث إلى v46 يحذف مخازن deutsch-pfad السابقة؛ أعد تشغيل المقاطع المطلوبة متصلًا قبل الاعتماد عليها دون اتصال. لا ضمان دائمًا ضد حصة التخزين أو حذف المتصفح للمخزن. المراجعة السمعية وتجربة الهاتف الحقيقي وSafari/Firefox ما زالت مطلوبة.

## البناء والتحقق

من مجلد المشروع:

```bash
python3 tools/build_course.py
python3 tools/verify_course.py
python3 tools/test_a0_01_review.py
node tools/test_progression.cjs
node tools/test_session_persistence.cjs
node tools/test_daily_plan.cjs
node tools/test_study_time.cjs
```

`build_course.py` يبني الحزمة من المصادر، و`verify_course.py` يفحص المحتوى والتقييمات والروابط وملفات MP3 بنيويًا. `test_a0_01_review.py` يحرس قرارات مراجعة A0.1 وبصماتها، ولا يثبت النطق. اختبارات Node المسماة progression وsession_persistence وdaily_plan وstudy_time تفحص على الترتيب أقفال التقدم والتحقق الذاتي، واستعادة الجلسات، وخطة اليوم، واحتساب الوقت الفعلي. نجاحها لا يثبت جودة النطق أو الإتقان التعليمي المستقل.

## التشغيل محليًا

تحتاج إلى Python 3 فقط:

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

ثم افتح `http://localhost:8000`. لا تفتح `index.html` مباشرةً من نظام الملفات؛ فالتطبيق يجلب بيانات المنهج بصيغة JSON.

## النشر

ارفع ملفات المشروع إلى GitHub، ثم اربط المستودع بـVercel كموقع ثابت؛ لا يلزم Build Command أو قاعدة بيانات. يمكن أيضًا نشره من جذر المستودع عبر GitHub Pages. التطبيق يدعم PWA والتخزين المحلي للعمل دون اتصال بعد تحميل ملفات التطبيق والمنهج.
