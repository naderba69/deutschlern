# دويتش — مساري الألماني

تطبيق ويب عربي باتجاه RTL لتعلّم الألمانية من A0 إلى B2، مصمم للعمل دون حساب أو قاعدة بيانات أو واجهات API مدفوعة. تُحفظ الإعدادات والتقدّم محليًا في متصفح المتعلم، ويمكن نشر المشروع كموقع ثابت على GitHub Pages أو Vercel.

## حالة المحتوى

أُدرجت في التطبيق **53 وحدة مصدرية**: 5 في A0 و12 في كل من A1 وA2 وB1 وB2. هذا يعني اكتمال الإدماج البنيوي، لا اكتمال التحقق التعليمي أو إثبات الوصول إلى B2. يحتوي كل درس على الشرح والمفردات والقواعد والحوارات ونصوص القراءة والاستماع والتمارين ومفتاح الإجابات.

ملفات `content/` هي المصدر التحريري الأساسي. أما `data/course.json` فيُولّد منها ليحمّله التطبيق. لا تعدّل HTML المولّد يدويًا؛ عدّل ملف Markdown ثم أعد البناء.

### التحقق البنيوي الحالي وحدوده

- تطابق الدروس الـ53 مع ملفات المصدر وتوزيع المستويات.
- رُصدت **428 عنوان تمرين** و**55 عنوانًا لأقسام الحوارات** في العرض المدمج.
- وجود مفتاح إجابات في كل درس، وفحص A0 من عشرة أسئلة، و**753 بطاقة مفردات** قابلة للمراجعة.
- فحص توازن وسوم HTML المولّدة وخلوّها من وسوم السكربت.
- فحوص الدمج بنيوية ولا تثبت وحدها كفاية المنهج أو إتقان المهارات. تقييمات دروس A0 وA1 الاثني عشر وبوابة الانتقال جاهزة، مع تحقق عملي ذاتي يعمل محليًا دون صوت أو خدمة خارجية.
- أزيل اختبار تحديد المستوى وخيار تغيير نقطة البداية، وأضيف تسلسل يمنع فتح درس تالٍ أو مستوى أعلى قبل 80% على الأقل وإكمال المهام العملية المطلوبة.
- **17 من 53** تقييم درس جاهزة (دروس A0 وA1)، وبوابة A0→A1 جاهزة بصورة مستقلة. يمكن إتمام A0 ثم إجراء البوابة؛ يظل A1 مقفلًا حتى اجتيازها. مقاطع A0 الـ27 جاهزة نهائيًا في الدروس المطابقة. وفي A1 أُنتجت 50 مقطعًا عبر 25 أصلًا حتى A1.11؛ بقيت 7 من أصل 32 أصلًا صوتيًا مخططًا للمستوى.

خريطة الإنتاج ومخرجات الدروس: [`data/course-improvement-plan.md`](data/course-improvement-plan.md) و[`data/curriculum-production-matrix.md`](data/curriculum-production-matrix.md). اكتملت تقييمات A0 وA1 وبوابة الانتقال. صوت A0 مكتمل بـ27 مقطعًا نهائيًا، وأُنتجت خمس دفعات صوتية لـA1 بمجموع 50 مقطعًا عبر 25 أصلًا حتى A1.11؛ لم يكتمل صوت A1 بعد.

## البناء والتحقق

من مجلد المشروع:

```bash
python3 tools/build_course.py
python3 tools/verify_course.py
node tools/test_progression.cjs
```

الأمر الأول يعيد إنشاء `data/course.json` من Markdown وملفات التقييم وقائمة الصوت، والثاني يفحص المحتوى والتقييمات وروابط الأهداف ومسارات MP3، والثالث يختبر أقفال التقدم ونتيجة 80% وحفظ مهام الأداء محليًا. فحص MP3 بنيوي فقط؛ لا يحكم على جودة النطق.

## التشغيل محليًا

تحتاج إلى Python 3 فقط:

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

ثم افتح `http://localhost:8000`. لا تفتح `index.html` مباشرةً من نظام الملفات؛ فالتطبيق يجلب بيانات المنهج بصيغة JSON.

## النشر

ارفع ملفات المشروع إلى GitHub، ثم اربط المستودع بـVercel كموقع ثابت؛ لا يلزم Build Command أو قاعدة بيانات. يمكن أيضًا نشره من جذر المستودع عبر GitHub Pages. التطبيق يدعم PWA والتخزين المحلي للعمل دون اتصال بعد تحميل ملفات التطبيق والمنهج.

## وظائف التطبيق الحالية وحدودها

- مسارات A0–B2 وقوائم الدروس والتقدّم المحلي مع تنزيل النسخ الاحتياطية واستردادها.
- نقطة البداية ثابتة عند A0؛ لا يوجد اختبار تحديد مستوى أو اختيار مستوى بدء.
- يمنع التطبيق فتح الدروس اللاحقة والمستويات الأعلى قبل استيفاء متطلبات الإتقان. لا يوجد زر لتسجيل الإكمال يدويًا. يتطلب التقييم الجاهز 80% على الأقل، وتغطية الأهداف، وإكمال دليل الأداء العملي المسجّل عندما يكون مطلوبًا.
- تقييمات A0 وA1 جاهزة: 10 أسئلة ومهمتا أداء لكل واحد من الدروس الـ17، إضافة إلى بوابة انتقال فيها 10 أسئلة و3 مهام. بعد 80%، يتطلب التقدم إكمال التحقق الذاتي العملي؛ تحفظ الأدلة محليًا ولا يُدّعى تصحيح النطق آليًا.
- توجد ورقة A0 قديمة من عشرة أسئلة بعتبة 7/10 في ملفات المحتوى، لكنها ليست بوابة الانتقال الجديدة ولا تُستخدم لفتح A1.
- اكتمل توليد 27 مقطعًا لـA0، وأُنتجت 50 مقطعًا صوتيًا لـA1 عبر خمس دفعات و25 أصلًا. جميع الأصول الـ37 بحالة `ready` النهائية بتوجيه المستخدم، وتظهر بوسم «نهائي» في الدروس المطابقة. لم أستمع إليها بنفسي. أُعيد إنتاج 4 تسجيلات A0 بصوت موحّد وبنصوص مصححة. واجهة المشغل تدعم سرعتين وتسلسل الحوار، وتخفي نص استماع البوابة حتى أول استماع. بقيت 7 من أصل 32 أصلًا مخططًا لـA1.
- بطاقات مراجعة للمفردات ونطق المتصفح متاحان عند دعم المتصفح. خيارات الهدف اليومي الحالية 10–30 دقيقة، والوقت المسجل يعتمد مدة الدرس المقدرة لا الوقت الفعلي. يتوفر نسخ احتياطي محلي بصيغة JSON.

**ملاحظة تعليمية:** تقييمات A0 وA1 مفعّلة بتحقق ذاتي محلي واضح، لا بتصحيح آلي للكتابة أو النطق؛ ولا تعتمد على الصوت. مقاطع A0 وخمس دفعات صوت A1 جاهزة للاستماع في الدروس المطابقة، وضُبطت حالتها `ready` النهائية بتوجيه المستخدم؛ لم أستمع إليها بنفسي. بقيت أصول صوت A1 قيد الإنتاج. انظر [`data/course-improvement-plan.md`](data/course-improvement-plan.md) و[`data/curriculum-production-matrix.md`](data/curriculum-production-matrix.md) للحالة التفصيلية.

## المصادر والحقوق

المحتوى التعليمي داخل `content/` مكتوب بصياغة أصلية، وتُستخدم الفهارس وخريطة الموضوعات في `data/source-plan.md` كمرجع لتخطيط المنهج. لم تُضمّن ملفات كتب PDF أو صفحاتها. قبل إضافة أي مادة مقتبسة إلى مستودع عام أو موقع منشور، تحقّق من أن الإذن يشمل المعالجة وإعادة النشر المقصودين.
