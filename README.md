# دويتش — مساري الألماني

تطبيق ويب عربي باتجاه RTL لتعلّم الألمانية من A0 إلى B2، مصمم للعمل دون حساب أو قاعدة بيانات أو واجهات API مدفوعة. تُحفظ الإعدادات والتقدّم محليًا في متصفح المتعلم، ويمكن نشر المشروع كموقع ثابت على GitHub Pages أو Vercel.

## حالة المحتوى

أُدرجت في التطبيق **53 وحدة مصدرية**: 5 في A0 و12 في كل من A1 وA2 وB1 وB2. هذا يعني اكتمال الإدماج البنيوي، لا اكتمال التحقق التعليمي أو إثبات الوصول إلى B2. يحتوي كل درس على الشرح والمفردات والقواعد والحوارات ونصوص القراءة والاستماع والتمارين ومفتاح الإجابات.

ملفات `content/` هي المصدر التحريري الأساسي. أما `data/course.json` فيُولّد منها ليحمّله التطبيق. لا تعدّل HTML المولّد يدويًا؛ عدّل ملف Markdown ثم أعد البناء.

### التحقق البنيوي الحالي وحدوده

- تطابق الدروس الـ53 مع ملفات المصدر وتوزيع المستويات.
- رُصدت **428 عنوان تمرين** و**55 عنوانًا لأقسام الحوارات** في العرض المدمج.
- وجود مفتاح إجابات في كل درس، وفحص A0 من عشرة أسئلة، و**753 بطاقة مفردات** قابلة للمراجعة.
- فحص توازن وسوم HTML المولّدة وخلوّها من وسوم السكربت.
- فحوص الدمج بنيوية ولا تثبت وحدها كفاية المنهج أو إتقان المهارات. تقييمات A0 وA1 وA2 وB1.1–B1.12 وB2.1–B2.2 وبوابة الانتقال جاهزة؛ تعتمد المهام العملية على تحقق ذاتي محلي دون صوت أو خدمة خارجية.
- أزيل اختبار تحديد المستوى وخيار تغيير نقطة البداية، وأضيف تسلسل يمنع فتح درس تالٍ أو مستوى أعلى قبل 80% على الأقل وإكمال المهام العملية المطلوبة.
- **تقييمات 43 من أصل 53 درسًا جاهزة** (A0 وA1 وA2 وB1.1–B1.12 وB2.1–B2.2؛ 430 سؤالًا و86 مهمة أداء)، وبوابة A0→A1 جاهزة بصورة مستقلة. لكل درس جاهز 10 أسئلة ومهمتا أداء؛ تُجرى البوابة بعد إتقان A0 ولا يفتح A1 قبل اجتيازها. أُنتج صوت B1.9 بخمسة أصول وعشرة مقاطع. إجمالي الحزمة 142 أصلًا و312 مقطعًا؛ 137 أصلًا جاهزة، بينما أصول B1.9 الخمسة متاحة للمعاينة مع النص بانتظار اعتماد اختيار الصوت. فُحصت الإطارات بنيويًا فقط ولم أستمع إلى التسجيلات.

خريطة الإنتاج ومخرجات الدروس: [`data/course-improvement-plan.md`](data/course-improvement-plan.md) و[`data/curriculum-production-matrix.md`](data/curriculum-production-matrix.md). اكتملت تقييمات A0 وA1 وA2 وB1.1–B1.12 وB2.1–B2.2 وبوابة الانتقال (430 سؤالًا و86 مهمة أداء للدروس). يفتح B2.1 بعد إتقان B1.12 ويفتح B2.2 بعد إتقان B2.1؛ وتبقى تقييمات B2.3–B2.12 غير جاهزة ومقفلة. التسجيلات موجودة حتى B1.9 (142 أصلًا و312 مقطعًا؛ 137 جاهزة وخمسة للمعاينة بانتظار اعتماد الصوت). فُحصت بنيويًا فقط ولم أستمع إليها.

## البناء والتحقق

من مجلد المشروع:

```bash
python3 tools/build_course.py
python3 tools/verify_course.py
node tools/test_progression.cjs
```

الأمر الأول يعيد إنشاء `data/course.json` من Markdown وملفات التقييم وقائمة الصوت، والثاني يفحص المحتوى والتقييمات وروابط الأهداف ومسارات MP3، والثالث يختبر أقفال التقدم ونتيجة 80% وحفظ مهام الأداء محليًا. فحص MP3 بنيوي فقط؛ لا يحكم على جودة النطق.

## التشغيل محليًا

تحتاج إلى Python 3 فقط:

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

ثم افتح `http://localhost:8000`. لا تفتح `index.html` مباشرةً من نظام الملفات؛ فالتطبيق يجلب بيانات المنهج بصيغة JSON.

## النشر

ارفع ملفات المشروع إلى GitHub، ثم اربط المستودع بـVercel كموقع ثابت؛ لا يلزم Build Command أو قاعدة بيانات. يمكن أيضًا نشره من جذر المستودع عبر GitHub Pages. التطبيق يدعم PWA والتخزين المحلي للعمل دون اتصال بعد تحميل ملفات التطبيق والمنهج.

## وظائف التطبيق الحالية وحدودها

- مسارات A0–B2 وقوائم الدروس والتقدّم المحلي مع تنزيل النسخ الاحتياطية واستردادها.
- نقطة البداية ثابتة عند A0؛ لا يوجد اختبار تحديد مستوى أو اختيار مستوى بدء.
- يمنع التطبيق فتح الدروس اللاحقة والمستويات الأعلى قبل استيفاء متطلبات الإتقان. لا يوجد زر لتسجيل الإكمال يدويًا. يتطلب التقييم الجاهز 80% على الأقل، وتغطية الأهداف، وإكمال دليل الأداء العملي المسجّل عندما يكون مطلوبًا.
- تقييمات A0 وA1 وA2 وB1.1–B1.12 وB2.1–B2.2 جاهزة: 10 أسئلة ومهمتا أداء لكل واحد من الدروس الـ43 (430 سؤالًا و86 مهمة أداء)، إضافة إلى بوابة انتقال فيها 10 أسئلة و3 مهام. في B2.1 يتطلب T08 وP01/P02 رابطًا للطريقة (`indem` أو `dadurch, dass`) ورابطًا للغاية (`um … zu`)؛ وفي B2.2 يختبر التقييم نقل المعلومات ونسبها إلى مصادرها باستخدام `Konjunktiv I`، مع بديل `Konjunktiv II` عند تطابق الجمع. تعرض الواجهة معايير الأداء المحلية. بعد 80%، يتطلب التقدم إكمال التحقق الذاتي العملي؛ تحفظ الأدلة محليًا ولا يُدّعى تصحيح النطق آليًا.
- توجد ورقة A0 قديمة من عشرة أسئلة بعتبة 7/10 في ملفات المحتوى، لكنها ليست بوابة الانتقال الجديدة ولا تُستخدم لفتح A1.
- اكتمل توليد 27 مقطعًا لـA0 و73 لـA1 و120 لـA2.1–A2.12، و10 مقاطع لكل درس من B1.1–B1.6، و12 مقطعًا لـB1.7، وعشرة مقاطع لكل من B1.8 وB1.9 عبر خمسة أصول لكل درس. الإجمالي **142 أصلًا و312 مقطعًا**؛ 137 أصلًا `ready`، وأصول B1.9 الخمسة ظاهرة للمعاينة في الدرس مع النصوص حتى اعتماد اختيار الصوت. لم أستمع إلى التسجيلات؛ فُحصت إطارات MP3 بنيويًا فقط.
- بطاقات مراجعة للمفردات ونطق المتصفح متاحان عند دعم المتصفح. خيارات الهدف اليومي الحالية 10–30 دقيقة، والوقت المسجل يعتمد مدة الدرس المقدرة لا الوقت الفعلي. يتوفر نسخ احتياطي محلي بصيغة JSON.

**ملاحظة تعليمية:** تقييمات A0 وA1 وA2 وB1.1–B1.12 وB2.1–B2.2 مفعّلة بتحقق ذاتي محلي واضح، لا بتصحيح آلي للكتابة أو النطق، ولا تعتمد على الصوت المولّد. 137 أصلًا صوتيًا `ready`؛ وأصول B1.9 الخمسة (10 مقاطع) ظاهرة للمعاينة في الدرس مع التفريغات، بانتظار اعتماد اختيار Mina وKarim. بقي التقييم مستقلًا عن التسجيلات. ثُبّتت أصوات الشخصيات كالتالي: B1.1 Lina=voice-00 وKarim=voice-03؛ B1.2 Mira=voice-02 وTarek=voice-03؛ B1.3 Nora=voice-02 وOmar=voice-03؛ B1.4 Nadia=voice-02 وFarid=voice-03؛ B1.5 Mara=voice-02 وYusuf=voice-03؛ B1.6 Hiba=voice-02 وFares=voice-03؛ B1.7 Laila=voice-02 وOmar=voice-03؛ B1.8 Mira=voice-02 وBilal=voice-05؛ B1.9 في المعاينة Mina=voice-02 وKarim=voice-03، والاختيار ينتظر اعتماد المستخدم. راوي المفردات والنماذج والقراءة voice-02 والاستماع voice-03، باستثناء قراءة B1.8 التي تقرؤها راوية مستقلة Erzählerin B1.8=voice-04 ولا تمثل Salma. لم أستمع إلى التسجيلات؛ فُحص MP3 بنيويًا فقط. انظر [`data/course-improvement-plan.md`](data/course-improvement-plan.md) و[`data/curriculum-production-matrix.md`](data/curriculum-production-matrix.md) للحالة التفصيلية.

## المصادر والحقوق

المحتوى التعليمي داخل `content/` مكتوب بصياغة أصلية، وتُستخدم الفهارس وخريطة الموضوعات في `data/source-plan.md` كمرجع لتخطيط المنهج. لم تُضمّن ملفات كتب PDF أو صفحاتها. قبل إضافة أي مادة مقتبسة إلى مستودع عام أو موقع منشور، تحقّق من أن الإذن يشمل المعالجة وإعادة النشر المقصودين.
